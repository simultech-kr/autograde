## 문제 상황과 학습 목표

실습실에는 온도를 측정하는 센서 하나와 벽면 화면, 조교 화면, 경고 화면이 있습니다.
새 화면이 추가될 때마다 센서 코드를 고치면 유지보수가 어려워집니다. 화면마다 다른 표현 방식까지
센서가 결정하면 구독 관리와 표시 기능이 서로 얽힙니다.

여러 화면이 센서를 구독·해지하고, 센서가 값을 발행할 때 현재 구독 화면에 알리는 프로그램을 만드세요.
화면의 메시지는 장식 객체를 조합하여 표현합니다. 실제 센서나 GUI를 연결하는 과제가 아니라,
표준 입력 명령으로 동작을 재현하는 콘솔 프로그램입니다.

- Observer 인터페이스를 통해 발행자와 구독자의 구체 타입을 분리합니다.
- 구독 순서와 객체 수명을 유지하면서 구독·해지를 처리합니다.
- 같은 Formatter 인터페이스를 따르는 Decorator를 중첩해 표현을 확장합니다.
- 객체 조합 순서가 출력에 미치는 영향을 설명합니다.

## 입력·출력 계약

첫 줄은 명령 수 N(1..100), 이어지는 N줄은 아래 명령입니다.
명령 이름·토큰 수·정수 형식은 올바릅니다. id는 영문 소문자·숫자·밑줄로 된 1..20자 문자열이며,
value는 -1000..1000입니다. 문자열은 대소문자를 구분합니다.

| 명령 | 성공 동작과 출력 | 오류 출력 |
| --- | --- | --- |
| `SUB id style` | 목록 맨 뒤에 구독 화면 추가, `OK id` | 이미 구독한 id이면 `ERROR duplicate`; 잘못된 style이면 `ERROR style` |
| `UNSUB id` | 해당 구독만 제거, `OK id` | 없는 id이면 `ERROR missing` |
| `PUBLISH value` | 구독 순서대로 각 화면의 알림 한 줄씩 | 구독자가 없으면 `NO_OBSERVERS` 한 줄 |

SUB는 **id 중복을 먼저**, style 유효성을 다음에 검사합니다. 실패하면 기존 구독과 장식이 바뀌지 않습니다.
해지 후 같은 id로 구독하면 맨 마지막에 추가됩니다. 발행은 목록을 바꾸지 않으며 같은 값을 여러 번
발행해도 매번 알립니다.

### 메시지 장식

기본 메시지는 `value=정수`입니다. style은 장식 없는 `-`, 또는 A/B만으로 된 길이 1..4 문자열입니다.
A/B는 반복 가능합니다. 다른 문자, `-A` 같은 혼합, 길이 5 이상은 오류입니다.

| 장식 | 현재 메시지에 적용하는 효과 |
| --- | --- |
| B | `[현재 메시지]` |
| A | `!현재 메시지!` |

**왼쪽부터 적용**합니다. BA는 대괄호를 만든 다음 느낌표로, AB는 느낌표를 만든 다음 대괄호로 감쌉니다.
최종 알림 형식은 `id: 메시지`이며 콜론 뒤에 공백 하나가 있습니다.

## 구현 단계

배포된 main.cpp는 컴파일 가능한 시작 코드이며 완성품이 아닙니다. 인터페이스를 유지하면서 필요한
멤버·보조 함수를 추가하고 TODO를 완성하세요.

1. 기본 문자열을 만드는 BaseFormatter를 구현하고 단독 출력을 확인합니다.
2. 내부 Formatter를 감싸는 BracketDecorator, AlertDecorator를 설계합니다. 두 장식을 겹칠 때
   어떤 객체가 바깥쪽이어야 하는지 먼저 종이에 적어 보세요.
3. id와 Formatter를 가진 DisplayObserver를 만들고 update()가 자신의 출력을 담당하게 합니다.
4. SensorSubject에서 중복 확인, 등록, 해지, 순서 보존, 빈 목록 알림을 구현합니다.
5. 명령 처리부가 규약 순서대로 검증하고 Formatter 조합을 가진 구독자를 등록하게 합니다.
6. 오류 이후 발행으로 기존 상태가 그대로인지 확인합니다.

센서는 구체 화면이나 장식 종류를 몰라야 합니다. 가능한 장식 문자열을 조건문으로 모두 나열하는
방식은 기능이 맞더라도 Decorator 구조를 보여 주지 못합니다.

## 공개 실행 예제

각 예제는 프로그램을 새로 실행하여 입력합니다. 서로 상태를 공유하지 않습니다.

### 예제 1 — 장식 순서 비교

입력
```text
3
SUB left BA
SUB right AB
PUBLISH -7
```

출력
```text
OK left
OK right
left: ![value=-7]!
right: [!value=-7!]
```

두 화면은 같은 -7을 받지만 바깥쪽 장식이 다릅니다.

### 예제 2 — 해지·재구독과 오류 후 상태 유지

입력
```text
10
PUBLISH 8
SUB panel A
SUB meter BB
SUB panel X
UNSUB panel
SUB panel BA
PUBLISH 12
SUB lamp XA
UNSUB unknown
PUBLISH -2
```

출력
```text
NO_OBSERVERS
OK panel
OK meter
ERROR duplicate
OK panel
OK panel
meter: [[value=12]]
panel: ![value=12]!
ERROR style
ERROR missing
meter: [[value=-2]]
panel: ![value=-2]!
```

SUB panel X는 style보다 중복 검사에서 먼저 실패합니다. panel은 재구독하며 meter 뒤로 이동합니다.
lamp의 등록 실패와 없는 id 해지는 이후 발행에 영향을 주지 않습니다.

## 빌드와 실행

Visual Studio 2022/2026 Community에서는 **C++를 사용한 데스크톱 개발** 도구를 준비하고,
CMakeLists.txt가 있는 이 폴더를 열어 lab 실행 대상을 빌드·실행합니다. 콘솔에는 예제 전체를 입력하세요.
예제를 input.txt에 저장했다면 Developer Command Prompt(CMD)에서 이 과제 폴더로 이동하여 실행할 수도 있습니다.

```bat
cl /std:c++17 /EHsc /W4 /utf-8 main.cpp /Fe:lab.exe
lab.exe < input.txt
```

위 입력 전달은 CMD 기준이며 PowerShell 문법이 아닙니다. Linux/macOS/WSL에서는 C++17 컴파일러를 준비한 뒤 이 폴더에서 실행합니다.

```sh
c++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o lab
./lab < input.txt
```

표준 입력만 읽고 표준 출력에는 규약의 결과만 쓰세요. 입력 안내문, 디버그 로그, 추가 메뉴,
종료 대기용 입력이나 system("pause")를 넣지 않습니다. 각 결과 줄 끝에는 줄바꿈을 출력합니다.
