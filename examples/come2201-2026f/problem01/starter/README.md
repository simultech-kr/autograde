# Week04 · Problem01: 스마트 실습실 센서 알림

## 문제 상황
실습실 온도 센서 하나를 여러 화면이 구독합니다. 화면은 독립적으로 구독·해지하며, 센서가 값을 발행하면 구독한 순서대로 알림을 받아야 합니다. 화면마다 메시지를 대괄호 또는 느낌표로 장식할 수 있고, 장식을 여러 겹 조합할 수 있어야 합니다.

`Observer` 인터페이스와 구독자를 관리하는 `SensorSubject`, 메시지를 만드는 `Formatter`와 이를 감싸는 decorator 객체들을 완성하세요. 센서는 화면별 장식 종류를 몰라야 합니다.

## 입력과 출력
첫 줄은 명령 수 N(1..100)입니다. 다음 N줄은 다음 중 하나입니다. 각 명령의 토큰 수와 정수 형식은 올바릅니다.

| 명령 | 동작과 출력 |
| --- | --- |
| `SUB id style` | 새 구독. 성공하면 `OK id`. 이미 존재하는 id는 `ERROR duplicate`. |
| `UNSUB id` | 해지. 성공하면 `OK id`, 없으면 `ERROR missing`. |
| `PUBLISH value` | 구독 순서로 `id: formatted-message`. 구독자가 없으면 `NO_OBSERVERS`. |

id는 영문 소문자/숫자/밑줄 1..20자, value는 -1000..1000입니다. 해지 후 다시 구독하면 맨 마지막에 추가됩니다. 중복 검사 후 장식 유효성을 검사합니다.

기본 메시지는 `value=정수`입니다. style은 `-`(장식 없음), 또는 A/B로 이루어진 길이 1..4 문자열입니다. 그 외에는 `ERROR style`이며 구독되지 않습니다.
- B: 현재 메시지를 `[메시지]`로 감쌉니다.
- A: 현재 메시지를 `!메시지!`로 감쌉니다.
- 문자열의 **왼쪽부터** 적용합니다. BA는 `![value=7]!`, AB는 `[!value=7!]`입니다.

### 예시
입력:
```text
3
SUB left BA
SUB right AB
PUBLISH -7
```
출력:
```text
OK left
OK right
left: ![value=-7]!
right: [!value=-7!]
```
