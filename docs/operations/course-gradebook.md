# 엑셀 성적표 배포

교수자가 작성한 중간고사·기말고사·출석 등 성적 항목을 수업별로 공개한다.
학생은 로그인한 본인의 학번에 연결된 값만 **내 점수**에서 확인한다. 자동채점 과제 점수와
교수자가 올린 성적표는 구분하며, 업로드한 값으로 자동채점 점수를 덮어쓰거나 총점을 다시 계산하지 않는다.

## 엑셀 준비

기본 형식은 첫 행에 항목 이름을 넣고, 학생마다 한 행을 사용하는 `.xlsx` 파일이다.

| 학번 | 중간고사 | 기말고사 | 출석점수 | 참여점수 |
| --- | ---: | ---: | ---: | ---: |
| 20260001 | 27 | 35 | 10 | 8 |
| 20260002 | 25 |  | 9 | 7 |

- **학번**은 수강생 명단과 정확히 일치해야 한다. 앞에 `0`이 있는 학번은 엑셀에서 셀 형식을 텍스트로 지정한다.
- 점수 항목 이름은 원하는 이름으로 정한다. 같은 항목 이름이나 같은 학번을 중복해서 넣지 않는다.
- 빈 셀은 미입력으로 표시한다. `0`은 0점으로 표시하며 빈 셀과 구분한다.
- 학생에게 보여 줄 정보만 넣는다. 내부 메모·비밀번호·다른 학생의 정보를 점수 칸에 넣지 않는다.
- 수식은 서버에서 실행하지 않는다. 수식의 계산 결과가 파일에 저장되지 않았다면 엑셀에서 계산·저장하거나 값으로 붙여넣은 뒤 다시 올린다.
- `.xls` 또는 매크로 통합문서 `.xlsm`은 `.xlsx`로 변환한 뒤 등록한다.
- 한 번에 최대 5 MiB, 학생 5,000명·점수 항목 100개까지 등록한다. 다른 시트의 불필요한 먼 셀이나 서식 때문에 제한에 걸리면 점수 표만 새 통합 문서로 복사한다.

## 교수자 등록·공개 흐름

1. 교수자 포털에서 해당 교과목·분반을 선택하고 **성적표 관리**를 연다.
2. **엑셀 양식 다운로드**에서 현재 수강생 학번이 입력된 파일을 받거나 기존 파일을 준비한다. 성적표 제목과 파일을 선택하여 업로드한다. 기본 배치는 **학생이 행**인 형식이며 학번 열 이름의 기본값은 `학번`이다. 시트 이름을 비워 두면 첫 시트를 읽는다.
3. 미리보기에서 점수 항목, 학생별 값, 수강 명단 매칭을 확인한다. 처음 100행을 화면에 표시하고 전체 학생 수를 함께 보여 준다. 잘못된 학번이나 중복 항목은 원본 엑셀에서 수정하여 다시 등록한다.
4. **공개할 항목**을 선택하고 내용을 확인한 뒤 **공개**한다. 선택하지 않은 열은 학생에게 제공하지 않는다. 업로드·미리보기만으로는 학생에게 공개되지 않는다.
5. 학생은 **내 점수 → 해당 수업 → 교수자 공개 성적**에서 자신의 항목별 값을 확인한다.

수정할 때는 완성된 최신 엑셀을 다시 업로드하여 검토한 후 공개한다. 수정본을 검토하는 동안에는
기존 공개본이 유지되고, 새 공개본을 적용하면 전체 성적표가 교체된다. 삭제한 학생 행이나 점수 항목도
새 파일 기준으로 반영되므로, 일부 수정한 행만 올리지 말고 공개할 전체 내용을 포함한다.

**학생 공개 중지**는 공개본을 학생 화면에서 숨긴다. 작성 중인 비공개 초안은 **삭제**할 수 있다.
과거 공개 이력과 수업 전체의 개인정보 파기는 아래 보관 절차로 관리한다.

기존 파일이 학생 학번을 열 머리글에 배치했다면 업로드에서 **학생이 열** 형식을 선택한다.
이 경우 A1은 `학번`, 첫 열의 두 번째 칸부터는 항목 이름, 첫 행의 두 번째 칸부터는 학생 학번을 넣는다. 일반적인 행 형식이 기본값이다.

관리 주소는 `/courses/{교과목 코드}/instructor/gradebook`, 양식 주소는 같은 경로의 `/template.xlsx`다.
직접 주소로 이동해도 교수자 로그인과 해당 수업 관리 권한이 필요하다.

## 접근과 보관

- 교수자는 권한이 있는 수업의 성적표만 관리한다. 학생에게 전체 엑셀이나 다른 학생의 행을 내려주지 않는다.
- 조회할 때마다 로그인·수강 상태를 확인한다. 수강이 중지된 학생은 이전 화면이나 주소로 다시 점수에 접근할 수 없다.
- 서버는 업로드한 원본 엑셀을 영구 파일로 보관하지 않고, 검증한 항목·값·공개 이력을 수업별 SQLite 데이터로 관리한다.
- 수업을 **보관**하면 성적표의 초안·공개본·학생별 점수를 파기한다. 이 성적표의 개별 점수는 연구 통계로 따로 남기지 않는다. 교과목을 **영구 삭제**할 때도 해당 수업의 성적표를 제거한다.
- 다른 수업의 성적표와 학생 계정은 해당 수업에 필요한 범위에서 유지한다.
- 기존 오프라인 명단 초기화 도구 `course_reset`은 학생 명단·제출 관련 명시된 범위만 초기화한다. 외부 입력 성적표는 자동 삭제하지 않으며, 같은 학생을 다시 등록하면 기존 공개 성적표가 다시 연결될 수 있다. 성적표의 공개를 끝내려면 성적표 관리에서 처리하고, 수업 전체를 파기할 때는 수업 보관·삭제 절차를 사용한다.
- 교수자의 원본 엑셀과 별도로 만든 백업은 서버 화면의 보관·삭제로 제거되지 않는다. 각 저장 위치에서 기관의 보관·파기 절차를 적용한다.

## 확인할 상황

- 학번이 맞지 않음: 업로드 파일의 학번 열과 해당 **분반**의 수강 명단을 확인한다.
- 점수가 보이지 않음: 초안 상태인지, 공개를 해제했는지, 학생 행이 새 공개본에 포함되었는지 확인한다.
- 빈 값과 0점: 빈 셀은 미입력, `0`은 입력된 점수다. 성적 합계·평균은 자동으로 추정하지 않는다.
- 수식 오류: 엑셀에서 오류를 수정하고 계산된 값을 저장하거나 값으로 붙여넣어 다시 업로드한다.
- 수정 충돌: 다른 교수자가 먼저 공개·변경한 경우 화면을 새로 열어 최신 공개본을 확인한 뒤 다시 처리한다.

## 서버에 반영할 때

서버에서 업데이트한 코드의 Python 의존성을 설치하고 기존 방식으로 서버를 재시작한다.
Next.js 학생 포털도 다시 빌드·재시작해야 **교수자 공개 성적**이 표시된다.

```sh
python -m pip install -e .
python -m pip check
```

Nginx를 사용한다면 [`config/nginx-autograde-portal.conf.example`](../../config/nginx-autograde-portal.conf.example)의
`/courses/.../instructor/gradebook/import` 전용 업로드 `location`을 현재 설정과 비교하여 적용한다.
이 경로는 `client_max_body_size 6m`이고, 앱은 엑셀 본문을 5 MiB까지 허용한다.
일반 요청 경로의 기본 64 KiB 제한만 적용되면 엑셀이 앱에 도착하기 전에 413 오류가 발생할 수 있다.
기존 서버 설정은 자동으로 덮어쓰지 않는다. 적용 후 `nginx -t`로 확인한 뒤 기존 운영 절차대로 다시 읽힌다.
