# 시험지 배포 사용 안내

실습 과제와 별도로 학생용 PDF 시험지를 배포한다. 학생은 기존 학번·전용 비밀번호로 웹에서 받으며, 확장 설치나 과제 수령 코드는 필요 없다. 시험 답안 수집·채점은 이 배포 기능에 포함하지 않는다.

학생마다 다른 PDF·ZIP을 배포하려면 [학생별 자료 배포](student-material-distribution.md)를 사용한다. 학번별 파일 등록과 본인 파일만 수령하는 기능은 별도 메뉴로 제공한다.

## 서버 반영

1. 서버를 정상 종료하고 사용 중인 데이터 폴더 전체와 설정 CSV를 백업한다. SQLite DB와 `exam-papers` 폴더를 함께 보관한다.
2. 변경된 코드를 반영하고 기존 가상환경에서 `python -m pip install -e '.[dev]'`를 실행한다.
3. 사용 중인 CSV에 기존 `instructor_assignment_web_enabled,true`가 설정되어 있는지 확인한다. 새 비밀번호·환경변수는 필요 없다.
4. [Nginx 예시](../../config/nginx-autograde-portal.conf.example)의 `/instructor/exam-papers/ep_.../upload` 전용 경로를 추가하고 운영자가 설정 검사 후 다시 읽힌다. 이 경로만 11 MiB 요청을 허용한다. 앱의 PDF 파일 제한은 10 MiB다. 일반 경로의 업로드 한도를 전부 늘리지 않는다.
5. 기존 `python -m autograde.pilot_portal_cli --config 사용중인설정.csv` 명령으로 다시 시작한다. DB는 최신 스키마로 자동 갱신되므로 갱신된 DB에 구버전 프로그램을 실행하지 않는다.

시험지는 `{data_root}/exam-papers`에 비공개로 저장된다. 이 디렉터리를 Nginx의 정적 파일 경로로 공개하지 않는다. 웹 포트는 기존 20010, 확장 API 포트는 기존 20000을 유지하며 시험지 전용 포트는 추가하지 않는다. 이번 기능에 Next.js 재빌드는 필요하지 않다.

## 교수자 배포

1. `https://ai.cbchoi.info:20010/instructor`에서 로그인하고 대상 수업·분반을 선택한다.
2. **시험지 배포**에서 제목, 학생 안내, 배포 시작·종료 시각을 입력하고 **초안 저장 · PDF 등록으로**를 누른다. 시각은 한국 표준시다.
3. 상세 화면에서 학생용 PDF를 저장한다. 정답, 채점 자료, 학생 개인정보는 포함하지 않는다.
4. **등록 PDF 다운로드·검토**로 저장된 파일을 확인한다. 페이지 누락·잘못된 정답 포함·일정 오류를 확인한다.
5. 수업이 운영 상태인지 확인하고 공개 확인란을 선택한 뒤 **시험지 공개**를 누른다. 시작 전 공개해도 파일은 시작 시각부터 받을 수 있다.
6. 화면에 표시되는 학생 시험지 접속 주소를 안내한다. 기존 수업은 `https://ai.cbchoi.info:20010/courses/come2201/exam-papers`이며, 분반 수업은 해당 수업의 고유 `course_key`가 들어간 주소를 사용한다.

공개 후에는 파일·안내·기간을 수정할 수 없다. 정정본을 배포하려면 새 시험지로 등록하고 기존 시험지를 **보관**한다. 보관하면 학생 접근은 즉시 종료되지만 이미 내려받은 파일을 회수하지는 못한다. 원본과 요청 기록은 교수자가 계속 확인할 수 있다.

## 학생 수령

1. 교수자가 안내한 시험지 주소를 실습 PC의 브라우저에서 연다.
2. 학번과 해당 수업의 학생 전용 비밀번호를 입력한다.
3. 제목·배포 기간을 확인하고 **시험지 PDF 다운로드**를 누른다. 시작 전·종료된 시험지에는 다운로드 버튼이 없다.
4. 브라우저의 다운로드 목록에서 파일 저장 여부를 확인하고 PDF를 연다. 답안은 시험지 또는 학생 안내에 적힌 방식으로 제출한다.
5. 공용 PC에서는 로그아웃한다. 저장된 PDF·답안 처리 방법은 교수자의 시험 운영 지침을 따른다.

인증은 10분 후 만료된다. 다운로드가 거절되면 목록에서 다시 인증하고 배포 기간을 확인한다. 기간 안에는 재다운로드할 수 있으며 요청 횟수는 증가한다. 비밀번호를 변경했거나 수강 상태가 중지되면 기존 세션으로 받을 수 없다.

## 요청 현황 확인

시험지 상세의 **학생별 파일 요청 현황**에서 학번·이름·수강 상태·최초 요청·최근 요청·횟수를 확인한다. 활성 학생 중 요청하지 않은 학생도 표시된다. 학생 초기화·수강 중지 이후에도 과거 요청 기록은 남는다.

이 기록으로 학생의 파일 저장 완료, 내용 열람 또는 시험 참석을 단정하지 않는다. 전송 중 연결이 끊어져도 승인한 요청 기록은 남을 수 있다. 실제 출석·답안 제출 여부는 별도 기준으로 확인한다.

## 시험 운영 전 확인

- 테스트 학생으로 배포 시작 전 거절, 시작 후 다운로드, 종료 후 거절을 확인한다.
- 다른 분반 학생과 로그아웃한 브라우저가 파일을 받지 못하는지 확인한다.
- 서버 시계, 외부 20010 접속, PDF 업로드 한도, 실제 PDF의 열림 여부를 확인한다.
- `pilot-local` 채점과 시험지 저장소가 같은 서버 권한을 쓰는 파일럿에서는 비밀 시험지 보호를 보장하지 않는다. 정식 시험에는 채점 실행 환경의 권한·저장소 격리가 필요하다.
