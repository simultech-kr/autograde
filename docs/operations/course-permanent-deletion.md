# 교과목 등록·수정과 영구 삭제

교과목명·학년도·학기·분반·설명·운영 상태는 기존 SQLite의 `admin_courses`에서 관리한다.
교과목 정보를 별도 CSV로 다시 작성할 필요는 없다. 학생 명단 가져오기와 서버 실행 설정 CSV는
각자의 용도로 유지한다. 교과목 등록·영구 삭제는 관리자 계정에서 수행하며, 담당 교수자는
허용된 수업의 정보 수정·운영 상태 관리를 사용한다. 기존 공유 교수자 인증 모드는 관리자 권한이다.

## 등록·조회·수정

1. 교수자 포털 `/instructor`에서 **교과목·분반 관리**를 연다.
2. **교과목·첫 분반 등록**에 코드, 수업명, 학년도, 학기, 분반을 입력한다.
3. 수업을 선택하여 **수업 설정**에서 정보를 보완하고 운영 상태를 선택한다.
4. 학생·과제·자료·제출 현황은 해당 수업 안에서 관리한다. 같은 학번의 다른 수업 기록은 분리된다.

새 수업은 준비 상태로 등록된다. 운영 후에는 수업명·설명은 수정할 수 있지만 교과목 코드·학년도·
학기·분반 식별자는 잠근다. 잘못 만든 분반은 삭제하고 올바른 분반을 새로 등록할 수 있다.

## 보관과 영구 삭제

보관은 학생 접속을 중단하면서 과제·제출·점수를 남긴다. 영구 삭제는 해당 수업의 데이터를
제거한다. **보관을 먼저 하지 않아도 준비·운영·보관 상태에서 영구 삭제할 수 있다.**
처리 중인 채점·과제 검증·콘텐츠 공개가 있으면 삭제를 중단하고 해당 작업 완료를 안내한다.

1. 삭제할 수업의 **수업 설정 → 교과목 영구 삭제 → 삭제 범위 확인**을 연다.
2. 표시된 수업명·학년도·분반과 수강 등록, 과제, 제출, 자료·콘텐츠 건수를 확인한다.
3. 관리 대상 파일의 수와 크기, 공용 저장소·캐시에 남기는 파일, 서버 관리 범위 밖의 원본을 확인한다.
4. 화면에 표시된 **정확한 교과목 키**를 직접 입력한다. 새 분반의 키에는 학년도와 임의 식별자가
   포함될 수 있으므로 일반 교과목 코드만 입력하지 않는다.
5. **교과목 영구 삭제**를 누른다. 미리보기 이후 데이터가 변경되면 새 범위를 검토하고 다시 입력한다.
6. 삭제된 수업은 목록과 학생 접근 경로에서 사라진다. 다른 수업과 공통 학생 계정은 유지된다.

삭제 대상은 해당 수업의 수강·인증·수령 코드, 과제 초안과 공개본, 제출·점수·설명 이력,
학생 활동, 수업 자료·콘텐츠·확장 배포 기록 및 수업 전용 관리 파일이다. 회원 계정은 여러 수업에서
공유하므로 유지하고 해당 수업의 가입·수강 명단 연결만 제거한다.

SQLite의 삭제 기록에는 재시작 때 삭제된 키를 되살리지 않도록 교과목 키·삭제 시각·집계·정리
상태를 남긴다. 이 기록에는 학생 비밀번호·소스·성적을 보관하지 않는다. 같은 과목을 다시 개설할
때는 새 수업으로 등록하여 새 키를 사용한다.

## 파일과 원격 공간 정리

파일은 SQLite 삭제가 확정되기 전에 같은 저장 장치의 비공개 임시 영역으로 옮긴다. DB 삭제가
실패하면 원래 위치로 되돌리고, 확정되면 임시 영역을 제거한다. 중간에 프로세스가 멈추면 재시작 시
DB 삭제 기록과 파일 이동 기록을 대조하여 복원 또는 정리를 계속한다. 학생 작업 저장이 진행 중이면
삭제가 경합하지 않도록 중단하고 재시도를 안내한다.

서버 밖에서 CLI로 등록한 원본, 공용 해시 저장소(CAS)·과제 준비 캐시, 기관이 별도로 만든 백업은
이 작업으로 삭제하지 않는다. 현재 다른 수업의 DB 참조가 없어도 파일 등록과 DB 확정 사이의
진행 중 요청이 있을 수 있으므로 온라인 수업 삭제에서 공용 파일을 회수하지 않는다. 삭제된 수업의
DB 연결과 조회·다운로드 권한은 제거된다. 공용 저장소의 불필요 파일을 회수하는 오프라인 정리 도구는
후속 기능이며 직접 파일을 골라 지우지 않는다. 수업의 파일 정리는 저장 매체의 포렌식 소거나 백업 폐기와 다르다.
원격 실습 기능이 활성화되어 있으면 DB 삭제 확정 후 실행 관리자에도 삭제를 전달하여 해당 키의
실행공간을 정리하고 지연된 새 실행을 거절한다.

## 정리 확인이 필요한 경우

DB 삭제 후 파일 또는 원격 공간 정리가 실패하면 **교과목 삭제 · 정리 확인 필요**로 표시한다.
학생 접근은 이미 차단되어 있지만 모든 자원이 삭제된 것으로 간주하지 않는다. 교과목 관리 아래의
**영구 삭제 기록**에서 상태를 확인하고 운영자가 파일 권한·저장 장치·실행 관리자 연결을 점검한다.
서버 재시작은 남은 정리를 재시도한다. 삭제 대기 폴더나 기록을 수동으로 지워 오류를 숨기지 않는다.
원격 정리는 삭제 당시 실행 관리자의 식별 정보를 확인하여 재시도한다. 실행 관리자 설정을 없애거나
다른 관리자로 바꾸었다는 이유만으로 기존 원격 공간의 정리가 완료된 것으로 표시하지 않는다.

이 기능은 운영 DB·파일을 직접 편집하는 절차를 대체한다. 구현 시험은 합성 수업으로 진행하며
운영 수업은 관리자 화면에서 대상과 영향 범위를 확인한 명시적 삭제 요청으로만 제거한다.
