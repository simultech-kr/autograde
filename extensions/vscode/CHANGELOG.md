# 변경 기록

## 0.5.22 — 수업 서버 자동 검색

- 학습 홈에서 같은 네트워크의 Autograde 서버를 검색하고 선택합니다. Mac IDE에서는 시작할 때 자동 검색합니다.
- 운영자가 등록한 기관 ID와 API·포털 주소가 일치하는 서버만 표시하며, 선택 시 HTTPS 상태를 확인합니다. 검색이 불가능하면 기존 주소 입력을 사용합니다.
- Mac 실행기는 별도 기관 설정 파일에 선택을 보관할 수 있습니다. 서명된 앱·학교 DNS·방화벽·기존 서버 설정은 수정하지 않습니다.
- 공용 실습 종료 후 학생 코드·자료·로그인 정보 정리와 다음 시작 시 잔여 파일 정리 정책을 유지합니다.
- Windows/WSL2 호스트 검색 전달은 후속 작업이며, 현재 원격 개발환경에서는 주소 입력을 사용합니다.

## 0.5.20 — 학습 홈에서 수령 코드와 서버 주소 직접 입력

- 학습 홈에 가려진 과제 수령 코드 입력란과 **코드로 연결** 버튼을 추가했습니다. 입력란의 Enter로도 연결합니다.
- 접힌 **서버 주소 설정**에서 채점 API 주소와 학생 포털 주소를 각각 입력·적용합니다. 명령 팔레트를 열 필요가 없습니다.
- 기존 수령 코드·서버 주소 명령도 학습 홈의 해당 입력란을 엽니다.
- 수령 코드 입력은 전송·화면 숨김·닫기 시 비우며 설정 파일에 저장하지 않습니다. 서버·세션이 바뀌면 진행 중인 연결을 중단하고 재입력을 안내합니다.
- 과제 다운로드·기존 과제 열기·공식 제출·결과 확인은 학습 홈 버튼에서 진행합니다. 폴더 선택·작업 영역 신뢰·본인 작업물 제출 확인과 공용 실습 종료 후 정리 절차는 유지합니다.
- 이번 변경은 VS Code용 확장과 이를 내장한 Autograde IDE에 적용합니다. Visual Studio 2022용 확장은 변경하지 않습니다.

## 0.5.19 — 학생 포털과 IDE 학습 흐름 통일

- 학습 홈에 현재 수업·과제와 다음 할 일을 표시하고 보조 도구를 접어서 제공합니다.
- 공식 제출 접수·채점 대기·채점 중·결과 공개 상태, 접수번호·시각과 이전 최고점을 구분합니다.
- 공개되지 않은 제출 점수는 과제 목록·학습 홈에 표시하지 않습니다.
- 학생 포털 주소를 채점 API 주소와 별도로 설정합니다. 작업 영역 설정은 무시하고 IDE 인증은 웹에 전달하지 않습니다.
- 자동 저장과 공식 제출을 구분하며 공용 실습실 종료 후 정리 동작을 유지합니다.

## 0.5.18 — 2026-10-28

- 원격 Linux 실습에 Python 3 실행을 추가했습니다. 로컬 Python 설치 없이 실행할 파일 1개와 표준입력을 선택합니다.
- 프로젝트의 다른 Python 모듈도 같은 서버 저장본에서 불러오며, 문법 오류·예외·시간 초과·출력 제한을 실행 결과에서 확인합니다. 별도 컴파일 단계가 없음을 구분해 표시합니다.
- 실행 전 서버 저장, 학생별 권한 확인, 읽기 전용 소스, 외부 네트워크 차단, 실습 종료 후 공간 삭제 정책은 C/C++와 동일합니다.
- 서버의 원격 실행 이미지를 함께 갱신해야 합니다. 추가 Python 패키지 설치, 디버거, 대화형 터미널은 포함하지 않습니다.

## 0.5.17 — 2026-10-28

- 학습 홈에 원격 C/C++ 실습을 추가했습니다. 승인된 서버 실행 환경에서 개인 공간을 준비하고 소스를 선택해 컴파일·실행합니다.
- 준비·실행·종료 전에 현재 코드의 서버 저장을 확인하고, 실행한 코드 버전과 컴파일/실행 출력을 구분합니다.
- 인증·서버·과제 변경 시 진행 중 요청과 화면 정보를 정리하며, 실행 중 편집한 코드를 이전 결과와 혼동하지 않도록 표시합니다.
- 공용 실습 종료에 원격 저장·삭제 확인을 연결했습니다. 정리 실패 시 재시도·내보내기 또는 정리 미확인 종료를 안내합니다.
- 서버 실행 관리자 설정이 필요합니다. 이번 버전의 원격 환경은 C17/C++17이며 디버거·Java/Python·대화형 터미널은 후속 범위입니다.
