# 교수자 웹 관리 MVP 검증 기록

일자: 2026-09-16. 환경: macOS, 로컬 SQLite 사본/새 임시 데이터, 합성 학생만 사용.
운영 서버·실제 학생 명단·실제 성적은 수정하지 않았다. 원격 배포 및 push도 하지 않는다.

## 구현 경계

- Controller/View: `instructor_web.py`, 기존 `platform_portal.py`·`platform_http.py`와 연결.
- Service/Repository: `course_admin.py`, `assignment_admin.py`; CLI/웹 공통 불변 등록·검증은
  `assignment_admin_operations.py`. SQLite 마이그레이션 11.
- 런타임: `course_runtime.py`의 전체 학생 공유 작업 풀과 별도 교수자 검증 작업자.
- 파일 처리: 버전 고정 `python-multipart==0.0.31`, 인증 후 경로별 크기 제한, ZIP 역할 분리.
- 기존 VS Code/Visual Studio API 계약과 학생별 수락 범위를 유지한다. 확장 바이너리는 변경하지 않았다.

## 수행한 시험

| 범위 | 확인 내용 |
| --- | --- |
| 수업·학생 서비스 | 수업/학기/분반 중복, 새 수업 활성화, 학생 추가·이름 수정·비밀번호 초기화·비활성화, 다른 수업 인증 보존 |
| CSV | 오류 시 전체 미적용, 원문 비밀번호 미저장·마스킹, 세션/수업 결합·10분 만료·동시 변경·재시도 처리 |
| 과제 | 실제 C/C++ 정답 10점·미완성 5점, 직접 입력 문제, 예제 Windows CMake starter, 비공개 파일 분리 |
| 공개 | 검증 전 차단, 편집 후 재검증, 중복 생성/공개 방지, 원본 보존 복제, 수락·제출 후 숨김 차단 |
| 오류 | 컴파일 실패·무한 반복·과다 출력·컴파일러 부재, 큐·재시작·실제 자식 프로세스 종료 |
| HTTP | 실제 multipart 업로드, 브라우저 textarea 줄바꿈, 인증 선행, 잘못된 Origin·쿠키·CSRF, 크기/중복 필드/중단 업로드 |
| 동적 연결 | 실제 서버 프로세스의 웹 수업 생성 → 운영 전환 → 학생 등록 → 로그인, 재시작 없이 성공 |
| 동시 처리 | 25개 동시 HTTP 클라이언트, 3개 수업의 제출 모두 공개 10점. 처리 중 네 번째 수업·학생 추가 성공, 학생 작업 스레드 4개 유지 |
| 세션 | 수업명/설명만 수정할 때 로그인 유지. 보관·재운영하면 이전 웹 쿠키·access/refresh 인증 재사용 불가 |
| 마이그레이션 | v10 데이터 보존, v11 초기화 실패 시 전체 롤백, 웹 부팅 모드 명시적 선택 및 최초 표식 보존 |
| 초기화 | 오프라인 미리보기·자동 백업·확인·초기화, 스키마 10/11 지원. 실행 중 서비스와 미완료 검증은 차단 |
| 브라우저 | 실제 로컬 브라우저에서 교수자 화면 탐색·여러 줄 문제 저장·검증 접수·정답 10/오답 5 결과 표시 및 배치 확인 |

시험 중 발견한 결함도 수정하고 회귀 시험을 추가했다:

1. multipart boundary를 기존 HTTP 파서가 거절하는 오류.
2. 교수자 View가 HTTP 전용 보안 헤더를 중복 반환해 500이 되는 오류.
3. textarea의 줄바꿈을 기존 URL-encoded 입력 검사에서 거절하는 오류.
4. 새 수업 런타임 생성 실패 후 잠금이 남아 재시도할 수 없는 오류.
5. 수업 설명 수정만으로 학생 로그인이 해제되는 오류 — 인증 상태 변경 번호와 편집 버전을 분리.
6. `_`/`-`로 시작하는 교과목 코드의 학생 URL이 일치하지 않는 오류 — 서버 생성 내부 키에 접두사 적용.

## 재실행

```sh
.venv/bin/python -m pytest -q
```

VS Code 확장 폴더에서는 다음을 실행한다.

```sh
npm test
```

최종 전체 서버 시험: **922개 통과, 19개 건너뜀, 실패 없음** (237.49초).
건너뛴 항목은 Windows/MSVC 2개, 동작 가능한 JDK가 필요한 Java 5개,
.NET 8 SDK가 필요한 Visual Studio 프로토콜 12개다.
VS Code 회귀 시험은 **132개 통과, 실패 없음**이다.
병렬 시험 간 공용 임시 폴더 충돌도 시험별 폴더로 격리한 후 전체 시험을 단독 재실행했다.

## 미실시·미포함

- 실제 `ai.cbchoi.info` HTTPS/Nginx 업로드와 Windows VS2022/2026 실기기 설치·제출은 수행하지 않았다.
- 위 25명 시험은 합성 HTTP 흐름이며 실제 25대 IDE 동시 사용이나 목표 p95 지연을 보증하지 않는다.
- 수업 전체 학생 기록의 온라인 초기화·자동 복원, 초안 자동 저장/이탈 확인은 구현 범위에서 제외했다.
- `pilot-local`은 보안 격리가 아니다. 일반 학생의 임의 코드와 공식 성적 운영은 여전히 별도 심사 대상이다.
