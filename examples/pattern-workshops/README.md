# C++17 패턴 실습: 문제 → 코드 작성 → 실행 → 프롬프트 검토

학생이 빈 부분을 직접 구현한 뒤 공개 테스트와 AI 검토 프롬프트로 확인하는 실습입니다.
기존 `observer-cpp` 과제를 변경하지 않는 별도 예제입니다.

| 실습 | 문제 상황 | 학생 배포 폴더 |
| --- | --- | --- |
| [옵저버](observer/starter/README.md) | 과제 마감 알림을 여러 화면에 전달하되 알림 게시판이 화면 종류를 몰라야 함 | `observer/starter` |
| [데코레이터](decorator/starter/README.md) | 교내 카페의 옵션 조합을 클래스 폭증 없이 가격·설명에 반영해야 함 | `decorator/starter` |

두 실습 모두 `pattern.hpp`의 TODO만 채웁니다. `main.cpp`는 시연, `check.cpp`는 공개 동작
검사, `REVIEW_PROMPT.md`는 구현 후 AI에게 전달할 검토 프롬프트입니다. 정답을 미리 생성하는
과제가 아니라 학생 구현과 실행 근거를 먼저 요구합니다.

- C++17을 사용합니다. VS Code/Linux·macOS·WSL2, VS2022/2026의 C++ 개발 환경을 대상으로 합니다.
- **학생에게는 각 `starter/`만 배포**하세요. `instructor/`에는 참고 구현이 있으므로 배포하지 않습니다.
- 명령줄 출력 확인과 AI 프롬프트 검토를 모두 제공합니다. AI 응답이 실제 실행 시험이나 교수자 평가를 대신하지 않습니다.
- 현재 서버에 등록·공개한 것은 아닙니다. `grade.py` 채점 어댑터도 이번 자료에는 없습니다.
  자동채점 서버에 올리려면 별도의 신뢰 채점기와 격리된 실행 환경을 연결해야 합니다.
- [교수자 운영·평가 안내](instructor-guide.md)를 참고하세요.
