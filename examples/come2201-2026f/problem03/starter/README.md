# Week06 · Problem03: 레거시 센서 통합 보고서
- 교과목: COME2201 / 마감: **2026-10-07 13:50 KST**
- C++17 / 제출: `main.cpp`
- 패턴: Adapter(Adaptor), Template Method

## 문제 상황
기존 섭씨 센서는 0.1도 단위 정수를, 기존 화씨 센서는 1도 단위 정수를 제공합니다. 두 레거시 API는 수정할 수 없습니다. 어댑터로 공통 섭씨(double) 데이터 소스로 연결하고, 보고서 생성의 공통 순서(읽기 → 변환된 값 필터링 → 집계 → 출력)를 Template Method로 구현하세요. 전체 관측값을 쓰는 보고서와 영하를 제외하는 보고서는 필터 조건만 다릅니다.

## 입력
첫 줄 `sensor policy N`, 다음에 N개의 정수 원시값이 공백으로 구분됩니다.
- sensor: C 또는 F. 그 외는 `ERROR sensor` 출력 후 종료.
- policy: ALL 또는 NONNEGATIVE. 그 외는 `ERROR policy` 출력 후 종료. 두 식별자가 모두 잘못되면 sensor 오류가 먼저입니다.
- N: 0..100. 원시값: -1000..1000. 정수 형식과 토큰 수는 올바릅니다.
- C는 원시값/10.0을 섭씨로 사용합니다.
- F는 (원시값-32)×5.0/9.0을 섭씨로 사용합니다.
- NONNEGATIVE는 **변환 후 섭씨가 0 이상**인 값만 유지합니다.

## 출력
유효한 센서/정책에 대해:
```text
COUNT 유지한_개수
MIN 최솟값
MAX 최댓값
MEAN 산술평균
```
모든 온도는 소수점 아래 정확히 한 자리(`std::fixed << std::setprecision(1)`)로 출력합니다. 채점 입력은 표현 결과가 플랫폼별 반올림 경계에 걸리지 않도록 구성합니다. 0은 `0.0`으로 출력합니다.

유지한 값이 하나도 없으면 MIN/MAX/MEAN 대신 아래 두 줄만 출력합니다.
```text
COUNT 0
NO_DATA
```

### 예시
입력:
```text
F ALL 3
32 68 104
```
출력:
```text
COUNT 3
MIN 0.0
MAX 40.0
MEAN 20.0
```
