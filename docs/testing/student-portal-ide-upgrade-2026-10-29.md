# 학생 포털·IDE 사용성 개선 검증

검증일: 2026-10-29. 로컬 합성 학생·임시 SQLite 환경에서 수행했다. 운영 서버의 학생 자료를 변경하지 않았다.

## 확인한 개선

- 실제 Next.js 학생 포털 `/app/student`: 가입 후 수강 선택, 명단 연결 상태, 계정 활성화·비밀번호 복구.
- 수업 홈: 과제·자료 진입, 수령 코드 발급, 공식 제출 상태와 이력.
- 최신 제출이 채점 대기이면 이번 점수는 미확정이며 이전 제출 최고 95점과 분리된다.
- 포털·IDE의 접수·대기·채점·공개 표현과 다음 행동을 통일했다. 자동 저장과 공식 제출은 별개다.
- 교수자 교실에서 조치 필요 학생을 선별한다. 같은 IDE 요청의 성공한 재시도는 이전 실패 표시를 해소한다.
- CSV 명단은 추가·교체 내역을 미리 본 뒤 확정한다. 공통 회원 비밀번호 복구는 관리자만 허용한다.

## 실제 브라우저 확인

로컬 프록시 18186, Next.js 18185, 임시 Python 서버를 연결했다.

1. 학번 20260001로 로그인하고 수업 홈을 열었다.
2. 현재 두 번째 제출의 채점 대기와 첫 번째 제출의 최고 95점이 분리되는 것을 확인했다.
3. 과제 수령 코드를 발급하고 숨겼다.
4. 수강 선택에서 COME3105를 신청하고 수강 중 표시를 확인했다.
5. 로그아웃 후 학번·수업 정보가 사라지고 로그인 화면이 표시되는 것을 확인했다.
6. 최종 화면에서 학기·분반 미등록 안내와 좁힌 상단 간격을 확인했다.

최종 화면은 `build/student-portal-upgrade/current-result.png`에 저장했다. 테스트 실행·사용법은
[학생 포털 운영 안내](../operations/student-portal-next.md)를 따른다.

## 배포물과 검증 범위

Mac 앱과 VS Code VSIX 0.5.19는 `dist/portal-ux-0.5.19/`에 생성했다. 번들 파일의 해시와 Mac 서명 검증을 통과했다.
Mac 앱은 로컬 파일럿용 임시 서명이며 공증된 배포본이 아니다. 기존 실행 중인 IDE는 종료하지 않았다.

운영 서버 반영, 운영 계정의 신규 가입·활성화 시험, Windows/VS2022 실행 시험은 수행하지 않았다.
운영 반영 시 Python·Next.js 갱신과 `/student/api/` Nginx 경로 적용이 필요하다.
