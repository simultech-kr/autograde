# 학생 화면 사용성 개선 (2026-09-22)

이 변경은 소스 구현입니다. 운영 서버 재시작이나 학생 PC의 확장 설치를 자동으로 수행하지 않습니다.
기존 학번·전용 비밀번호, 과제별 일회용 수령 코드와 현재 수락한 과제만 표시하는 정책을 유지합니다.

## 학생 웹

- `/courses/come2201`, `/courses/come2201/login` 최초 접속에는 비밀번호 오류를 표시하지 않습니다.
  유효한 웹 로그인 중 `/login`을 열어도 인증을 지우지 않고 과제 목록을 표시합니다.
- 수령 가능한 공개 실습만 **마감 임박순**으로 표시하고, 마감 미지정 과제는 뒤에 배치합니다.
  마감은 `2026년 9월 23일(수) 13:50 · 한국 시간` 형식입니다.
  24시간/7일 이내 마감 표시를 추가했습니다.
- 선택한 실습 제목과 코드 발급 버튼은 목록을 스크롤해도 화면 아래에서 확인할 수 있습니다.
  매우 낮은 창에서는 고정 영역을 풀어 내용을 가리지 않습니다. 라이트/다크 테마를 지원합니다.
- 코드 발급 화면에 코드·API 주소 복사, 남은 유효 시간, VS Code/Visual Studio 연결 방법이 나옵니다.
  휴대전화에서 발급했다면 실습 PC에서 코드를 직접 입력해야 합니다. 복사는 기기 사이 전송 기능이 아닙니다.
- 클립보드 권한이 없거나 HTTP 파일럿이면 텍스트 선택과 수동 복사 안내로 대체합니다.
  JavaScript가 꺼져 있어도 로그인·선택·발급 및 만료 시각 확인은 가능합니다.
- 발급 후 웹 로그인은 기존처럼 종료합니다. **다시 인증하여 새 코드 받기**에 재로그인 필요성을 명시합니다.
  코드가 확장에서 사용되었는지는 웹이 실시간 조회하지 않으므로 남은 시간이 있어도 재사용할 수 없습니다.
- 실습 선택 후 공개 상태가 바뀌면 비밀번호 오류 대신 수령 불가 원인을 안내하고 목록을 다시 표시합니다.

학생용 스크립트는 내용 해시가 일치하는 고정 코드만 허용합니다. 인증정보를 localStorage 등에
저장하지 않으며 외부 스크립트, 외부 통신, 추가 권한을 허용하지 않습니다.

## 확장

VS Code는 제출 전 **해당 과제 폴더의 미저장 문서**를 확인합니다. 저장을 취소하거나 실패하면
전송하지 않습니다. 처음 수령 코드를 입력하기 전에 작업 폴더 준비를 안내합니다.
접수된 제출의 결과를 접수번호에 고정해 자동 확인하며, 결과 창에서 다시 확인할 수 있습니다.
새 제출·로그아웃·과제 전환 이후 오래된 조회 결과로 화면을 덮지 않도록 분리합니다.

Visual Studio는 미제출 상태를 오류가 아닌 안내로 표시합니다. 자동 조회 도중 인증이 만료되면
로그인 화면과 접수번호 안내를 표시합니다. 과제를 바꾸면 이전 다운로드 진단을 지웁니다.
제출 확인창 안에서 전체 파일 목록을 스크롤·복사한 뒤 제출하거나 취소할 수 있습니다.

## 적용과 확인

1. 변경한 서버 소스를 운영 환경에 반영하고 **기존에 사용하는 설정으로 서버를 재시작**합니다.
   학생 웹 수정만을 위해 설정 CSV·Nginx 경로·포트·DB를 변경할 필요는 없습니다.
   프록시에서 별도 CSP를 덧붙이면 학생 스크립트가 차단될 수 있으므로 응답 정책도 확인합니다.
2. [VS Code 0.5.5 설치 파일](../../extensions/vscode/autograde-vscode-0.5.5.vsix)을
   `Install from VSIX...`로 설치하고 창을 다시 로드합니다. Marketplace 서명·게시본은 아닙니다.
3. Visual Studio 0.5.6 소스는 Windows의 기존 빌드 절차로 VSIX를 만들고 설치·재시작합니다.
   macOS의 소스 검사만으로 Windows WPF 동작이나 VSIX 설치 성공을 보장하지 않습니다.
4. 학생 웹 최초 접속 → 마감순 선택 → 코드 복사 → 폴더 준비 → 확장 로그인·다운로드를 확인합니다.
5. 코드 수정 후 **저장하지 않은 채 제출**하여 저장 확인을 시험합니다. 접수번호가 나타난 뒤
   새 제출의 점수가 자동 표시되는지, 재제출 중 이전 결과가 덮이지 않는지 확인합니다.
6. 공용 PC에서는 로그아웃하세요. 내려받은 소스 파일은 자동 삭제되지 않습니다.

## 재현 가능한 검증

```sh
.venv/bin/python -m pytest -q tests/integration/test_student_portal_ux.py tests/integration/test_course_portal.py tests/integration/test_instructor_browser.py
```

위 테스트의 `test_export_student_browser_fixtures`가 임시 디렉터리에 출력한
`student-browser-fixtures.json`으로 실제 브라우저 검사를 실행할 수 있습니다.
Playwright와 Chrome 실행 파일 경로는 개발 환경에 맞게 지정합니다.

```sh
node scripts/check_student_browser.cjs <student-browser-fixtures.json> <playwright-module-path> <chrome-binary>
```
